## How tools are selected

Entries are chosen by hand. A tool gets in when most of the following hold:

- It has a working official website and is actively available.
- AI is central to what it does, not a feature bolted onto the marketing page.
- It solves a problem someone would recognise without a demo.
- There is enough public information to describe it accurately.
- It adds something the other tools in its category do not already cover.

Things that keep a tool out: broken or parked sites, abandoned products, pure affiliate
landing pages, near-identical clones, and anything that only turned up because someone
asked for a listing.

Ordering inside each category is alphabetical. Position carries no meaning, and there is no
paid placement, sponsorship, or affiliate link anywhere in this repository.

Pricing labels use a fixed vocabulary — `Free`, `Freemium`, `Paid`, `Open Source`,
`Free Trial` — because exact prices go stale within weeks. Platform labels are only applied
where they are reliable and actually useful.
