## البرمجة

محرّرات ووكلاء وأدوات مراجعة تكتب الشيفرة أو تقرأها.

- **[Aider](https://aider.chat/)** — مبرمج مرافق في الطرفية يعدّل ملفات مستودعك المحلي ويسجّل التغييرات أولًا بأول. `Open Source` `CLI`
- **[Bolt](https://bolt.new/)** — من وصف نصي إلى تطبيق ويب يعمل في المتصفح، مع بقاء المشروع قابلًا للتعديل والنشر. `Freemium` `Web`
- **[Cline](https://cline.bot/)** — وكيل داخل VS Code يقرأ المشروع وينفّذ الأوامر ويستأذن قبل تطبيق أي تعديل. `Open Source` `VS Code`
- **[CodeRabbit](https://www.coderabbit.ai/)** — يراجع طلبات الدمج سطرًا بسطر ويعلّق مباشرة على GitHub وGitLab. `Freemium` `Web`
- **[Continue](https://continue.dev/)** — إكمال تلقائي ومحادثة داخل محرّرك، موجَّهان إلى النموذج الذي تختار تشغيله. `Open Source` `VS Code` `JetBrains`
- **[Cursor](https://cursor.com/)** — محرّر مبني حول محادثة تدرك قاعدة الشيفرة وتعديلات تمتد عبر ملفات متعددة. `Freemium` `Windows` `macOS` `Linux` · [مقارنة مع GitHub Copilot](https://tiorai.com/compare/cursor-ai-vs-github-copilot/)
- **[Devin](https://devin.ai/)** — وكيل البرمجة من Cognition، وهو الآن بيئة سطح المكتب التي حلّت محل Windsurf. `Paid` `Web` `Windows` `macOS` `Linux`
- **[GitHub Copilot](https://github.com/features/copilot)** — إكمال ومحادثة ومساعدة في طلبات الدمج داخل المحرّرات الشائعة وعلى GitHub نفسه. `Freemium` `VS Code` `JetBrains` `CLI`
- **[Replit](https://replit.com/)** — بيئة تطوير في المتصفح مع وكيل يبني المشاريع ويشغّلها ويستضيفها دون إعداد محلي. `Freemium` `Web` · [بدائل](https://tiorai.com/alternatives/replit-ai-alternatives/)
- **[Tabnine](https://www.tabnine.com/)** — إكمال شيفرة مع استضافة ذاتية ونشر معزول عن الشبكة للفرق الخاضعة لقيود تنظيمية. `Freemium` `VS Code` `JetBrains` · [مقارنة مع Cursor](https://tiorai.com/compare/cursor-ai-vs-tabnine/)

- **[Gemini Notebook](https://notebook.google/)** — كان اسمه NotebookLM: يبني إجاباته حصرًا على المصادر التي ترفعها، ويولّد منها ملخصات. `Freemium` `Web`

## كيف تختار الأدوات

الاختيار يدوي. تدخل الأداة القائمة إذا تحقق معظم ما يلي:

- لها موقع رسمي يعمل، والمنتج متاح فعليًا.
- الذكاء الاصطناعي جوهر عملها، لا خاصية مضافة إلى صفحة تسويقية.
- تحلّ مشكلة يتعرّف عليها القارئ دون الحاجة إلى عرض توضيحي.
- تتوفر معلومات عامة كافية لوصفها بدقة.
- تضيف شيئًا لا تغطّيه بقية أدوات القسم.

وما يُبقيها خارجًا: المواقع المعطّلة أو المركونة، والمنتجات المهجورة، وصفحات الإحالة
التجارية، والنسخ المكرّرة بلا فارق حقيقي، وكل ما ظهر لمجرد أن أحدهم طلب إدراجه.

الترتيب داخل كل قسم أبجدي. الموضع لا يعني شيئًا، ولا يوجد في هذا المستودع أي إدراج مدفوع
أو رعاية أو رابط إحالة.

وسوم التسعير محصورة في خمس قيم — `Free` و`Freemium` و`Paid` و`Open Source` و`Free Trial` —
لأن الأسعار الدقيقة تتغير خلال أسابيع. ووسوم المنصات تُضاف فقط حين تكون موثوقة ومفيدة فعلًا.
